# Yusen Liu – Personal Site

Source for [somerandomethan.github.io](https://somerandomethan.github.io): Yusen Liu's portfolio. Yusen is a baseband software engineer at Ericsson working on 5G NR and applied AI.

A static site (HTML, CSS, vanilla JS) served by GitHub Pages from `master`. To preview locally, open `index.html` or run `python3 -m http.server`.

Content follows Yusen's CV and is current through March 2026.

Based on the free [Smith portfolio template](https://github.com/codewithsadee/smith-portfolio) by codewithsadee.
