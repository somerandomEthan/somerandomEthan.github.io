Projects

Selected Work

  • Ericsson · 2025–2026

    Nabu AI Platform

    Agent + RAG platform (LangChain / LangGraph) that turns test requirements, slides, PDFs and spreadsheets into searchable knowledge and generated test cases. Took the work from proof of concept to reusable platform features for RAN testers and baseband designers, covering model selection, document chunking, vector-store and retrieval design, and structured output through prompt engineering.

  • Ericsson · 2025

    TestShift Toolkit

    Led an agent-based tool that migrates hardware C unit tests to Python host-based tests, with a generate → execute → verify loop and skills shared across the team.

  • Ericsson · 2024–present

    5G NR Uplink Stream Service

    New uplink stream service in C for ORAN NG-OLLS Cat-A with a Block Floating-Point compressed frequency-domain data path under strict real-time limits, plus timing consistency checks and cmocka CI tests.

  • UCL · 2023

    Automated Wound-Care Robot

    Robotic arm combining computer vision and a 3D-printed dressing module. UNet segmentation on Jetson Orin Nano (Dice 0.79), about 3 s response and 100% localisation accuracy over 10 trials.

  • University of Leeds · 2021–2022

    Two-Wheeled Self-Balancing Robot

    Inverted-pendulum PID control fusing IMU (I2C) and Hall encoder data, recovering from disturbances in 1 s. Android Bluetooth remote and a custom LM2596 buck-converter PCB.
